# Meta-Major Prompt Collection

## Prompt Description  
"The data for majors is hosted at [Insert JSON file link here]. Based on this data, generate a 2-year meta-major plan for the following majors: '[Insert Major Name]'. Provide a detailed and structured list of suggested courses or pathways, including:  

1. **Year-wise and Semester-wise Breakdown**: Organize the courses for each year and semester.  
2. **Course Categories**: Clearly label courses as major-specific, general education, or electives.  
3. **Course Details**: Include course codes (if available in the data) and a brief description.  
4. **Recommendations**: Suggest prerequisites or skills needed for advanced courses.  
5. **Plan Balance**: Ensure a mix of foundational knowledge, intermediate studies, and interdisciplinary opportunities. The plan should offer flexibility for customization based on individual preferences or career goals."
